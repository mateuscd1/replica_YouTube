# Replicação da Página do Youtube usando apens HTML e CSS

O sistema em questão é usado uma interface estática, em que é feito a réplica em HTML e CSS do Youtube, os comandos
e as configurações em CSS foram utilizadas a partir da observação do site YouTube.com, alguns dos ícones usados foram retirados a partir da própria plataforma. Essa réplica foi feita apenas com intuito de aprimorar meus estudos sobre HTML e CSS ⚠️ Reitero que tudo foi usado com fim de aprendizado sobre programação Front-End, e que todos os direitos e direitos de marca são servados a plataforma do YouTube.

## English Version

The system in question uses a static interface, replicating YouTube's HTML and CSS. The commands and CSS settings were taken from YouTube.com, and some of the icons used were taken from the platform itself. This replication was done solely to enhance my HTML and CSS studies. ⚠️ I reiterate that everything was used for the purpose of learning front-end programming, and that all rights and trademark rights are served by the YouTube platform.
